# rethink
AIを用いて人間の議論を支援するツールです。各参加者はAIと1対1で対話を行い、議題に対する意見やその根拠を抽出します。そしてその際に各参加者の意見や考え方をもつエージェントが作成されます。その後作成されたエージェント同士が議論を行って、妥協点を提示したり議論の流れをマインドマップとして可視化したりして、人間がその後の議論を行うための土台とします。

## 使用する技術スタック

| 領域 | 技術 |
|---|---|
| フロントエンド | HTML / CSS / Bootstrap / JavaScript |
| バックエンド | Node.js / Express |

## クレジット

本プロジェクトは GDGoC Japan Hackathon 2026 にて4名のチームで開発した作品をフォークしたものです。
オリジナルのリポジトリは [こちら](https://github.com/Keon-Dev/a) です。

チーム開発では、議論ページを除く各画面（ルーム作成・ロビー・対話・対話終了待ち）の
設計・実装を担当しました。Express によるサーバ構築、対話パートと議論パートをつなぐ
データ受け渡しの設計、Socket.IO を用いた複数タブでの同時進行機能の実装も行っています。
（議論ロジック本体は他メンバーが担当しています。）

フォーク後は、アプリ全体のデザインを一貫性のあるものに統一する改修を個人で行いました。

---

## 主な機能
- セッションの作成と、招待URLによる参加
- AIとの1対1の対話による意見収集
- 参加者の考えを反映したエージェントの作成
- エージェント同士によるAI議論
- 議論結果のマインドマップの表示
- 対立点、合意点、問いの提示

## ローカルでの起動方法

### 必要な環境
- Node.js 22以上推奨

### セットアップ

1. リポジトリをクローン
```bash
git clone https://github.com/sk-dev0/rethink.git
cd rethink
```

2. 依存関係をインストール
```bash
npm install
```

3. 環境変数を設定

`.env` ファイルを作成し、以下の変数を設定してください。
```
PROJECT_ID=
LOCATION=
SESSION_SECRET=
```

4. 開発サーバーを起動
```bash
cd server
nodemon server.js
```

[http://localhost:3000](http://localhost:3000) をブラウザで開いてください。
